# Aura Maze

Aura Maze is a web-based gaming platform built with React and Vite, featuring a curated game library, user accounts, subscriptions, and a dark neon-inspired interface.

## Project Status

Aura Maze is currently under active development.

The application, game library, navigation, account system, and payment functionality are being developed and refined before the project is released commercially.

## Games & Licensing

The licensing status of games and assets in this repository is being reviewed individually.

At this time:

* Games currently available through the **Library** are usable within the project.
* Free games displayed on the **landing page** require additional licensing/source review.
* Other games, artwork, logos, fonts, audio, branding, labels, source code, and third-party assets may have their own licensing requirements.
* Third-party material is **not automatically covered by the license of the Aura Maze project**.

Commercial use and paid distribution of Aura Maze are intended only after the project is fully completed and the necessary rights, permissions, and licenses have been reviewed and confirmed.

Until that review is complete, no blanket commercial-use rights are granted for third-party games or assets included in this repository.

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
